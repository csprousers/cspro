The development of the Census and Survey Processing System (CSPro) is managed by the U.S. Census Bureau's International Programs Center. The following programs are used to develop the software:

  • Microsoft Visual Studio Professional (C, C++, C#)
  • Android Studio (C, C++, Java, Kotlin)
  • Emscripten (C, C++, JavaScript)
  • NSIS: Nullsoft Scriptable Install System (install package)
  • wkhtmltopdf (help documentation)

The software uses several open-source software packages, the licenses of which follow the CSPro license.
